Here a list of advantages that can be achieved when working with Info Graphs. It may be that the categories below should be a header (possible a page on their own) Each bullet point might be good enough for a sub section with its own sub header. Hardware/power requirements: - small data transfers which is good for smaller devices as well as good for the internet when seen in a broader sense. (many has to share the same infrastructure) - save data storage space, which is good for bother smaller devices, but also projects relying on big data. - save processing power by having tiny documents and not much parsing due to data being compact and binary, which is good for bother smaller devices, but also projects relying on big data. Methodology: - atomic change on large model possibility - atomic responsibility delegation possibility - starting from scratch making a micro protocol - more privacy Data structure features for data operations: - uniform data operation and structure - can be decorated indefinitely - the ability to describe in more detail increase exponentially when decorating.
